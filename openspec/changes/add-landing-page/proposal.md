# Add public landing page

## Why
First impression for the samaj. Guests (mostly on phones) need an attractive, trustworthy page that explains the platform and drives registration.

## What
- `/` landing page (hero, live counters, news/poster carousel, events, how it works, features, success stories, FAQ, CTA, footer, PWA install button).
- Public layout `layouts.public`.
- Static pages: terms, privacy (DPDP Act 2023), about, faq (Hindi + English).
- Logged-in active members are redirected to `home`, admins to `admin.dashboard`.

## Out of scope
Admin management of news/stories (other module), Marathi content.
